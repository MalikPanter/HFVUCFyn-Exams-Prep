**Bemærk:** Der findes forskellige læreplansår og tilhørende formelsamlinger. Vælg aldrig automatisk den nyeste uden at fastslå elevens gældende læreplan.

## Offentligt indhold, som kan tilføjes

- `assignments/`: selvskrevne opgaver med løsninger, tydeligt mærket som øvelser.
- `tools/`: egne gennemgange af metoder, definitioner og henvisninger til officielle formelsamlinger.
- `exam/`: verificerede regler, eksamensformat og tilladte hjælpemidler i den relevante termin.

Private elevfiler må ikke offentliggøres her.
