**Status:** Kildeindgang, ikke færdigt pensum.

## Kildeverificeret eksempel: Matematik C på toårigt hf, 2024

[Officiel læreplan, Matematik C toårigt hf august 2024](https://uvm.dk/media/0e1jxnvs/240613-matematik-c-toaarig-hf-august-2024.pdf) — **kontrollér elevens gældende planår**.

- Pkt. 4.2 skelner mellem **centralt stillet skriftlig prøve** (todelt, med forskellige hjælpemiddelregler) og **mundtlig prøve**. Gælder for denne 2024-læreplan, ikke automatisk tidligere/andre versioner.
- Pkt. 4.3 fremhæver ved den skriftlige prøve bl.a. **matematiske begreber, symbol- og formelsprog, modellering og digitale værktøjer**.
- Ved den mundtlige prøve fremhæves **begreber, enkle ræsonnementer, symbolsprog og matematisk formidling**.

ChatGPT skal derfor lave korte trin-for-trin-forklaringer med **hvorfor en metode virker**, mellemregninger og eksempler, ikke bare formler og facit. Formelsamling og tekniske værktøjer skal tilpasses præcis læreplan og prøveform.

## Offentligt indhold, som kan tilføjes

- `assignments/`: selvskrevne opgaver med løsninger, tydeligt mærket som øvelser.

- `exam/`: verificerede regler, eksamensformat og tilladte hjælpemidler i den relevante termin.

Private elevfiler må ikke offentliggøres her.
