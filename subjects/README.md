# Fag og niveauer

Her samles **offentligt delbare** faglige indgange: kontrollerede kilder, vejledninger, egenproducerede forklaringer og lovlige øvelsesmaterialer.

**Dette er ikke elevens private dokumentmappe.** Elevens egne noter, opgaver og PDF-pakke ligger altid der, hvor eleven selv vælger at opbevare dem.

## Sådan bruges fagoversigten

1. Find fag og niveau.
2. Kontrollér, om fagets krav gælder **toårigt hf** eller **hf-enkeltfag**. Læreplanerne er ikke nødvendigvis ens.
3. Kontrollér læreplansår og den konkrete eksamenstermin.
4. Brug kun kildeverificerede krav til dækningstjek.
