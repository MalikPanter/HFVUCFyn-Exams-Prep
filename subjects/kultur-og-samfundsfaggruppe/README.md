# Kultur- og samfundsfaggruppen (KS) — toårigt hf

**Status: Kildefagprofil 16.11.2026 — eksempel fra 2022-læreplanen.** Verificér elevens planår, termin og prøveform.

Faggruppen omfatter **historie B, religion C og samfundsfag C**. Historie B under KS er **ikke** automatisk identisk med Historie B på hf-enkeltfag.

## Hvad bedømmes?

Pkt. **4.2** beskriver både en **intern flerfaglig prøve** og **enkeltfaglige prøver**. Pkt. **4.3** angiver, at fællesprøvens vurdering tager udgangspunkt i de samlede faglige mål, mens enkeltfagsprøverne vurderes efter de relevante historiefaglige, religionsfaglige eller samfundsfaglige dele af målene.

## Hvad skal ChatGPT fokusere på?

- Fælles problemstillinger og sammenhænge mellem historie, religion og samfundsfag.
- Fagenes **forskellige metoder**: kildearbejde, analyse af religion og samfundsfaglige data, når det er relevant for den dokumenterede læreplan og elevens forløb.
- Eksplicit kobling mellem dokumentation fra elevens noter og de faglige mål.
- Tydelig skelnen mellem intern flerfaglig og eventuel enkeltfaglig prøve.

**Undgå at påstå noget om elevens konkrete udtrukne fag, som ikke er dokumenteret.**
